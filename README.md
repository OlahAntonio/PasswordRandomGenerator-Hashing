🔐 Password Generator & Hashing App

A simple web application built with Flask that generates secure passwords, validates their strength, and stores them safely in a MySQL database using bcrypt hashing.

🚀 Features

🔑 Generate strong random passwords
✅ Validate password strength:
Uppercase letters required
Lowercase letters required
Numbers required
Special symbols required
Length between 8–16 characters
🔁 Confirm password matching check
🔒 Secure password hashing using bcrypt
💾 Store passwords securely in a MySQL database
❌ Delete stored passwords by ID
👁️ Show/hide password toggle (frontend JS)
⚡ Simple and responsive UI using Bootstrap

🛠️ Tech Stack
Backend: Flask (Python)
Database: MySQL Workbench
Security: bcrypt hashing
Frontend: HTML, Bootstrap 5, JavaScript
